# SlideSleuth MCP

SlideSleuth connects compatible desktop agent hosts to the SlideSleuth Desktop
app on the same Mac. It is a local MCP integration, not a hosted service.

For current host requirements, installation, and troubleshooting, see the
[setup guide](https://www.slidesleuth.com/agent-access/).

For privacy information or support, see the [Privacy Policy](https://www.slidesleuth.com/privacy/)
and [contact page](https://www.slidesleuth.com/contact/).
